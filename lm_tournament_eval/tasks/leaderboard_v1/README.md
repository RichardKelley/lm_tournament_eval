# Leaderboard V1 Evaluations

This group reproduces as closely as possible the evaluations used in the original version of the Open LLM Leaderboard on Hugging Face.

The list of tasks used to generate that leaderboard is:

- ARC
- Hellaswag
- MMLU
- TruthfulQA
- Winogrande
- GSM8K

The original leaderboard tasks were abandoned in favor of a new set that powers the current (as of Sept 2024) version 2 of the Leaderboard. The reasons for that decision were articulated in a blog post [here](https://huggingface.co/spaces/open-llm-leaderboard/blog). In spite of those good reasons, we provide this group to enable the comparison of weaker models.
